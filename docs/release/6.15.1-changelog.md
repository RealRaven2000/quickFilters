**Important Changes**

This update lets you run multiple backups and restores in a day using a single trial session, and makes the Filter Assistant clearer and more reliable.

_whats-new-list_

Maintenance Update 6.15.1

- Run multiple backups and restores on the same day while seeing your remaining trial sessions. [issue 193]
- Create or merge filters from multiple selected messages and browse their previews from the assistant. Fixed previews when moving messages using the Thunderbird context menu. [issue 405] [issue 407]
- The troubleshooter shows its remaining trial sessions and gives results more room, with compact controls and a collapsible checks panel. [issue 401]
- A clearer, responsive Filter Assistant previews the actions of the selected merge target. Closing or cancelling it no longer sometimes prevents it from reopening. [issue 404]
- A fully themed license registration tab replaces the old dialog. [issue 406]


Highlights from version 6.15

- Multi-account filter backup and restore, with free trials for this Pro feature. [issue 193]
- A dedicated filter troubleshooter to find and resolve filter problems. [issue 401]
- Improved Pro feature trial tracking and refreshed trial allowances. [issue 400]
