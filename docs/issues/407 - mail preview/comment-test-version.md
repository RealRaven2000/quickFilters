This test version fixes the empty email preview when moving messages with Thunderbird's **Move To** context menu while the assistant is active. It captures the message details before the move, so they remain available to the assistant.

When multiple messages are selected, use the `<` and `>` buttons beside the preview to browse their details.

[quickFilters-6.15.1pre57.zip](https://github.com/user-attachments/files/35033012/quickFilters-6.15.1pre57.zip)

**To install:** Download the ZIP file, then drag the downloaded ZIP directly into Thunderbird's Add-ons Manager. **Do not extract it first**—the extracted contents cannot be installed this way.
