Title: Activated Filters Teaching only adds/merges a new filter for one email when more than one email has been selected.


Activated Filters Teaching in Thunderbird:

Selecting Multiple Emails: The user selects multiple separate email messages in the email list (specifically, three messages from different senders).

Creating/Merging Filters: By right-clicking the selected emails and navigating through the menu to create a message filter, the interface prompts the user to either merge with an existing filter (such as "SPAM") or create a new filter.

Adding New Rules to the Filter: When merging the selection into an existing filter ("SPAM"), the system adds the sender information/rules corresponding to only one of the selected emails rather than incorporating all of the selected emails into the filter rules.
