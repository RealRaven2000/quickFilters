**Improvements**

*   Made quickFilters compatible with Tb 141.*
*   Added a new context menu option to run filters automatically on folders other than Inbox (IMAP only).
*   Improved duplicate filter detection related to tags.

**Bug Fixes**

*   Major update to support changes in Thunderbird 141.* {L2}{L1} Fixed critical issue caused by Thunderbird changing how folder names are handled internally. [issue #308]
*   Fixed an issue with custom fields (%from(domain)%, %from%) creating empty search terms during mail moves and filter merges. [issue #301]
