This release adds multi-account filter backup and restore, a dedicated filter troubleshooter, and improved handling of premium feature usage. Enhancements
  • Backup and restore: Save and restore filters for multiple accounts or selected accounts. #193
  • Filter troubleshooter: Check your filters for problems and choose how to fix them. A Pro feature with a limited number of free trials. #401
  • Premium feature usage: Fix blocking warnings for filter sorting and advanced filter search. Explain when all free trial attempts for a Pro feature have been used. Reset trial usage through Config Editor without importing old countdown values. Treat negative usage counts as zero. Enforce folder-search trial limits and require a valid Pro license for Local Folders autorun. #400
  • Internal cleanup: Move backup/restore and filter-review operations into the experimental FiltersAPI. Remove redundant add-on prefixes from localization keys. #402
The full history with screenshots is available in the quickFilters Change Log. All development and free support work for quickFilters is financed via the quickFilters Pro license, which also adds additional features.
